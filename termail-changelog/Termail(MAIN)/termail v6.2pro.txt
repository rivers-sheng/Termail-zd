Termail v6.2 → v6.2 Pro 更新说明
版本号：6.2.0 → 6.2.0_Pro（versionCode 11 → 12，标签 Termail_v6.2 → Termail_v6.2_Pro）

一、新增
PRoot 多发行版支持（commands/proot_commands.cpp）

新增 getDistro / setDistro / getRootfs 三个 lambda 辅助函数，发行版标记存于 proot-env/distro

distro [list|alpine|ubuntu]：发行版切换命令

list：列出 alpine / ubuntu 安装状态与当前发行版

distro ubuntu：未安装时自动从 :/resources/proot/ubuntu.tar 解压（分块读写，120 秒超时），完成后切换

distro alpine：切换回 Alpine

proot-shell：按当前发行版选择 rootfs 路径与 shell（Ubuntu 用 /bin/bash，Alpine 用 /bin/sh），工作目录 -w /root

proot-mirror：按发行版写不同镜像源（Ubuntu 用 ubuntu-ports jammy，Alpine 用 v3.19）

proot-install：Ubuntu 走 apt update && apt install -y，Alpine 走 apk add --no-cache

proot-status：显示 proot、当前发行版、Alpine、Ubuntu 四项状态

proot-setup：Alpine 安装完成后写入 distro 标记为 alpine

pre-position 命令

输出一份完整的前置命令清单（PRoot 环境、软件安装、多会话、网络工具、SSH、日志、设置），并给出完整安装顺序建议（get-busybox → proot-setup → proot-mirror → proot-update → distro ubuntu → proot-install coreutils）

资源

CMake 资源列表新增 resources/proot/ubuntu.tar

三、其他
