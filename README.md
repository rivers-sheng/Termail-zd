# Termail-zd

一款运行在 Android 上的**终端模拟器**。

底层基于 **C++** 与 **Qt6** 构建，将极客级的终端体验完美复刻到了移动端。它不仅仅是一个简单的命令执行器，更内置了网络服务、脚本引擎与海量游戏。

## ✨ 核心特性

### 🖥️ 沉浸式终端体验
- 原生 C++ 打造的命令行交互逻辑，支持历史命令（上下键）、Tab 自动补全、快捷清屏。
- 完整的文件系统操作支持：查看、切换、编辑、运行。
- 内置交互式编辑器，支持直接在终端内预览与修改代码。

### 🌐 全栈级网络服务 (`serve`)
- **内置 HTTP 文件服务器**：一行命令，将手机瞬间变成局域网 NAS。
- **完整用户权限系统**：支持多用户登录，区分 `root`（超级管理员）与普通用户，细粒度控制 `读 (r) / 写 (w) / 执行 (x)` 权限。
- **在线文件管理**：通过浏览器即可完成文件浏览、上传、下载、新建目录、在线代码编辑及批量删除。
- **安全防护**：SHA-256 加盐密码存储，随机会话 Token，及关键操作的 `sudo` 二次身份验证。

### 🐚 内嵌脚本引擎
- 集成 **Lua 5.4** 引擎，支持直接在终端中编写并执行 Lua 脚本。
- 自动化的最佳伴侣，可深度定制你的终端工作流。

### 🎮 内置游戏大厅 (`TermailGames` 分支)
在等待编译或排查 Bug 的间隙，终端内直接召唤游戏：
- 包含 30 款经典小游戏：俄罗斯方块、贪吃蛇、扫雷、中国象棋、围棋、五子棋、数独、2048、打飞机等。
- 零外链纯本地 HTML5 渲染，瞬间唤醒。

## 🛠️ 技术栈
- **核心语言**：C++17 / C
- **UI 框架**：Qt 6 (Widgets & Core)
- **跨平台支持**：Android (NDK) / 桌面端
- **构建系统**：CMake + Gradle
