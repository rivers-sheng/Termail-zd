// 01 简介

为什么是 Termail

大多数 Android 终端方案依赖 PRoot 容器或打包一整份 busybox，体积大、启动慢、与系统环境隔离。 Termail 走另一条路：不搬运运行时，直接复用系统自带的 toybox 与原生二进制， 把体积压到 10 MB 出头，启动压到毫秒级。

SIZE

轻量

无 PRoot、无内置 busybox，APK 约 10.8 MB。不额外搬运运行时，安装即用。

NATIVE

原生工具链

强制通过系统 toybox 或安卓原生命令执行，与系统环境保持一致。

STABLE

稳定优先

去掉启动期异步自检，改用硬编码白名单，规避 SIGSEGV 与主线程卡死。

SERVE

内置 HTTP 服务

独立线程运行，支持多用户权限、在线状态轮询、HTML 运行器与 IP 黑名单。

EDITOR

图形化编辑器

全屏编辑、查找替换、行号显示与滚动同步，适合手机小屏操作。

SSH

主机管理

ssh-host / ssh-connect / ssh-keygen / ssh-tunnel 一整套命令封装。

// 03 架构

核心设计决策

当前架构是在多次崩溃、白屏与内存爆满之后收敛出的最优解。以下机制请勿轻易改动，每一条都对应过具体的事故。

01

无 PRoot / 无内置 busybox

所有底层依赖强制通过系统自带的 toybox 或安卓原生命令执行，避免运行时搬运带来的体积与兼容问题。

02

去掉 QProcess 异步自检

不在启动时用 QProcess 探测底层命令（ssh、vi 等）。这类探测极易导致 SIGSEGV 或卡死主线程，已彻底移除。

03

白名单机制（Self-check.txt）

纯 C++ 实现与确认存在的系统命令，硬编码在 utils/selfcheck.h 的 getSafeBuiltins() 中。首次启动由底部状态栏以 QTimer 异步、逐条、10ms 低超时探测外部命令，生成 settings/termail/Self-check.txt。全程不弹窗、不阻塞主线程。

04

UI 交互分层

help 只显示 242 个核心命令，more 显示 118 个外部扩展命令，两者均支持关键词模糊筛选，例如 help <命令> 与 more <关键词>。

05

HTTP 服务器（serve）安全优先

独立线程/页面运行，已实现多用户权限、在线状态轮询、HTML 运行器、重命名/移动文件、日志持久化与 IP 黑名单。维护时优先保证密码哈希与 http_users.json 不外泄。

06

ssh 交互模式已知风险

底层安卓 ssh 在无 TTY 环境下可能崩溃。已在 v6.6.1 中加入参数校验与护栏，用户主动执行时给出明确提示，避免进程段错误。

注意：外部命令（如 apt、gcc、git、vim）的实际运行依赖第三方环境（Termux 或已 Root 的手机）。普通手机未安装对应环境时，会提示“命令未找到”，属预期行为。

// 06 维护

给后续维护者的建议

以下每一条都来自实际事故，建议在改动前先读一遍。

◆

不要再接入“全自动检测”

安卓底层环境差异过大，越测越崩溃。核心命令写死在 getSafeBuiltins() 里是唯一正解。

◆

修改 setupUI() 时别弄丢 QScrollBar

滚动条样式与 QTextEdit viewport 耦合，在安卓终端上极难排查。改完务必在真机上用触摸拖拽验证一次，模拟器行为不同。

◆

维护优先度

serve 网页端安全性（密码存哈希、不泄露 http_users.json） > 终端输入输出流畅 > 命令响应提示。

◆

构建与复现

源码位于 /home/sheng/Termail_final_patch4/，修改后执行 ./build_apk.sh。建议在无 gradle 缓存的 clean 环境跑一次，确认 APK 可独立构建。

◆

Self-check.txt 会陈旧

用户更换 ROM 或安装 Termux 后，旧的探测文件会与实际环境脱节，需要提供手动“重新探测”入口，但绝不可自动触发。

// 07 FAQ

常见问题

为什么执行 apt、gcc、vim 提示“命令未找到”？
Termail 不内置这些外部工具，它们依赖第三方环境（Termux 或已 Root 的手机）。普通手机未安装对应环境时，提示“命令未找到”属预期行为，不是 Bug。
ssh 连接时提示无 TTY 或直接退出怎么办？
安卓底层 ssh 在无 TTY 环境下可能失败。v6.6.1 已加入护栏，会给出明确提示而非崩溃。交互式 ssh 的完整支持需要底层环境配合，暂时以提示为主。
help 和 more 有什么区别？
help 列出 242 个核心命令，more 列出 118 个外部扩展命令。两者都支持关键词筛选，例如 help ssh 或 more git。
Self-check.txt 里的命令不全或过期了？
该文件在首次启动时生成，反映当时的系统环境。更换 ROM 或安装 Termux 后可能陈旧。建议通过手动入口重新探测，而不是依赖自动检测。
内置 HTTP 服务安全吗？
serve 运行在独立线程，支持多用户权限、密码哈希存储与 IP 黑名单。使用时请勿将 http_users.json 暴露在静态路由下，并注意路径穿越与 URL 编码绕过风险。
编辑器为什么改成全屏？
手机横屏时，固定尺寸的对话框容易留边或被系统重排。全屏窗口配合 Qt::Window 与 showFullScreen()，能稳定占满真实屏幕，同时保留 Esc 与关闭按钮的可靠退出。
