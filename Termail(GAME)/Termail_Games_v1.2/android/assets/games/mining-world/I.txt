mining world（挖矿世界 / 2D 挖矿）

玩法目标
一个横版的 2D 世界，由方块组成。往下挖，挖到更值钱的矿石，分数越高；同时能放置方块、自由探索。越深越刺激。

操作方式

← → 左右移动；

跳 按钮跳跃；

点方块 → 挖掉它（挖模式），材料进背包、加分；

点空位 → 放方块（放模式），用背包里的材料；

模式：挖 / 放 切换；

底部物品栏点选材料（有数量才能选）。

规则要点

挖：点方块挖掉，材料进背包、加分；

放：把选中的方块放到空位，必须挨着已有方块（不能凭空放）；

不能挖自己脚下的方块（防掉进自己挖的坑）；

挖矿有距离限制（太远挖不到，防止隔屏乱点）；

物理：重力、跳跃、和方块的碰撞——站不住会掉，站到实心方块上才稳；

相机跟随，你走到哪看到哪。

世界 / 矿石

世界 60 格宽、200 格深，出生点在地表中间；

地层：草 → 土 → 石，石头里按深度埋不同的矿：

浅层：煤、铁；

中层：金、铁、煤；

深层：钻石、金、铁、煤；

越深越值钱，越挖越刺激。

功能 / 分数

挖矿加分：草 0、土 1、石 2、煤 5、铁 10、金 20、钻石 50；

飘字：挖到矿有 +5 / +20 飘字，反馈清楚；

顶部显示分数 / 深度 / 最高分，最高分存在浏览器里；

深度：越往下深度数越大。

小提示

别乱挖脚下：会掉下去，先看好下面；

往下挖：越深矿石越值钱，但也越难爬上来；

放方块：能当梯子，挖坑后用土填回去慢慢爬。
